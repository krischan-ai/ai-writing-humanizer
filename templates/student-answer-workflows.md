# Student Answer Workflows

## Short Answer

Use for homework and tutorial questions.

Workflow:

1. Identify what the question directly asks.
2. Answer the main point in the first sentence.
3. Add one or two supporting explanations.
4. Remove unnecessary background information.

## Lab Report

Workflow:

1. Keep scientific terminology.
2. Describe variables clearly.
3. Avoid exaggerated conclusions.
4. Link results to observations.

Example style:

"The response variable is the softness rating of cooked rice. Participants will evaluate each sample and provide a score from 1 to 10. The average score will be used to compare the treatments."

## Statistics Question

Workflow:

1. State the method or formula.
2. Explain why it applies.
3. Interpret the result in simple language.
4. Avoid only giving textbook definitions.

## Business Case

Workflow:

1. Identify the business problem.
2. Use evidence from the case.
3. Discuss practical impact.
4. Avoid generic strategy language.

## Reflection

Workflow:

1. Describe the actual learning point.
2. Explain how understanding changed.
3. Avoid fake personal stories.
4. Keep the tone natural.
