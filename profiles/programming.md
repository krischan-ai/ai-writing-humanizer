# Programming Assignment Profile

## Use for

- programming homework
- code explanation
- algorithm questions
- debugging reports
- computer science assignments

## Answer style

Prefer:

- explain the idea before implementation
- describe trade-offs briefly
- use precise technical terms
- connect code behavior to the question

Avoid:

- unnecessary software engineering buzzwords
- explaining every obvious line of code
- generic statements like "technology is important"

## Typical structure

Problem understanding

Implementation approach

Complexity analysis (when relevant)

Limitations or possible improvements

## Code explanation rule

Do not only describe what the code does.
Explain why the design choice was made.
