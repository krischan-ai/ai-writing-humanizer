# Finance Assignment Profile

## Use for

- finance homework
- investment analysis
- valuation questions
- market reports

## Answer style

Prefer:

- define assumptions clearly
- separate calculation from interpretation
- explain risk factors
- distinguish facts from opinions

## Typical structure

Assumption

Calculation

Result

Financial interpretation

## Avoid

- unsupported market predictions
- exaggerated claims
- generic investment language

Example:

Instead of:

"This investment has great potential."

Use:

"Based on the given assumptions, the expected return increases, but the result is sensitive to changes in the discount rate."
